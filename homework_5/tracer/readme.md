# Tracer

Декоратор хранит текущую глубину рекурсии. Перед вызовом он печатает `->`, увеличивает глубину, после возврата уменьшает её и печатает `<-` вместе с результатом.

Накладные расходы одного вызова: O(1) без учёта вывода, глубина рекурсии не меняется.

```text
-> factorial(2)
  -> factorial(1)
  <- factorial(1) = 1
<- factorial(2) = 2
```
