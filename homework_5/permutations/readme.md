# Permutations

Backtracking выбирает очередной элемент, рекурсивно переставляет оставшиеся и отменяет выбор. `show_trace=True` включает декоратор, показывающий стек вызовов.

Время: O(n · n!), память результата: O(n · n!), стек: O(n).

```text
[] -> [1] -> [1, 2] -> [1, 2, 3]
          -> [1, 3] -> [1, 3, 2]
```
