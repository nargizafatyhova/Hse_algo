# Two sum

Сохраняем в словаре уже просмотренные числа и их индексы. Для каждого `arr[i]` ищем `k - arr[i]`. Если число найдено, возвращаем его индекс и `i`.

Время: O(n). Память: O(n).

Пример для `[1, 3, 4, 10]`, `k = 7`: после чисел 1 и 3 словарь равен `{1: 0, 3: 1}`. Для 4 находим дополнение 3 и возвращаем `(1, 2)`.

Файлы: `main.py` — решение, `test_main.py` — тесты.
