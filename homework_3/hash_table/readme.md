# Hash table

Таблица хранит список корзин, а каждая корзина — список пар `[ключ, значение]`. Индекс корзины равен `hash(key) % capacity`. Коллизии решаются цепочками: ключ ищется внутри одной корзины.

При заполнении более 75% таблица удваивается, а при заполнении менее 25% уменьшается. Внутреннее хранилище использует только `list`.

В среднем `put`, `get` и `remove` работают за O(1), в худшем случае при множестве коллизий — O(n). Память: O(n).

Пример: при ёмкости 4 ключи с хешами 1 и 5 попадают в корзину 1: `[[key1, value1], [key2, value2]]`. Поиск сравнивает ключи этой цепочки.

Файлы: `main.py` — реализация, `test_main.py` — тесты.
