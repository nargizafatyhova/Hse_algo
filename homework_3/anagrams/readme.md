# Anagrams

У анаграмм совпадает набор отсортированных букв. Используем его как ключ словаря и добавляем слово в соответствующую группу.

Время: O(n · m log m), где n — число слов, m — максимальная длина слова. Память: O(n · m).

Пример: `eat -> aet`, `tea -> aet`, `tan -> ant`, `ate -> aet`. Получаем группы `[eat, tea, ate]` и `[tan]`.

Файлы: `main.py` — решение, `test_main.py` — тесты.
