# Tree Traversal

BST хранит меньшие значения слева, большие — справа. Вставка спускается до свободного места. Обходы отличаются порядком посещения узла `N`, левого `L` и правого `R` поддеревьев: `NLR`, `LNR`, `LRN`, `NRL`, `RNL`, `RLN`.

Вставка: O(h), один обход: O(n), память рекурсии: O(h), где h — высота дерева.

```text
    8
   / \
  3  10
```

Для него preorder: `[8, 3, 10]`, inorder: `[3, 8, 10]`, postorder: `[3, 10, 8]`.
