# Validate BST

Для каждого узла передаём допустимый интервал значений. При переходе влево верхняя граница становится значением узла, вправо — нижняя. Нарушение строгой границы означает, что дерево не BST.

Время: O(n). Память: O(h) для стека рекурсии.

```text
   10
  /  \
 5   15
    /  \
   6   20
```

Узел 6 находится справа от 10, но меньше 10, поэтому результат `False`.
