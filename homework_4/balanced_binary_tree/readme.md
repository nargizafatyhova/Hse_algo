# Balanced Binary Tree

Рекурсивно вычисляем высоты поддеревьев. Значение `-1` означает, что найден дисбаланс, и сразу передаётся выше. Для остальных узлов проверяем разницу высот.

Время: O(n), каждый узел посещается один раз. Память: O(h).

```text
    1
   /
  2
 /
3
```

У корня высоты поддеревьев равны 2 и 0, разница больше 1 — результат `False`.
