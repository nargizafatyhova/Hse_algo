# Проверка последовательностей стека

# Решение

Создаём пустой стек и по очереди добавляем в него элементы из `pushed`.

После каждого добавления сравниваем вершину стека с очередным элементом `popped`. Пока они равны, удаляем вершину и переходим к следующему элементу `popped`.

Если в конце стек пуст, последовательность удаления возможна. Если в стеке остались элементы, получить `popped` с помощью операций со стеком нельзя.

# Сложность

Время: O(n), потому что каждый элемент один раз добавляется в стек и не более одного раза удаляется.

Память: O(n), в худшем случае в стеке находятся все элементы.

# Пример работы

Для `pushed = [1, 2, 3, 4, 5]` и `popped = [1, 3, 5, 4, 2]`:

| Действие | Стек | Ожидаем удалить |
| --- | --- | --- |
| push 1, pop 1 | [] | 3 |
| push 2 | [2] | 3 |
| push 3, pop 3 | [2] | 5 |
| push 4 | [2, 4] | 5 |
| push 5, pop 5 | [2, 4] | 4 |
| pop 4 | [2] | 2 |
| pop 2 | [] | всё удалено |

Стек пуст, поэтому ответ `True`.
