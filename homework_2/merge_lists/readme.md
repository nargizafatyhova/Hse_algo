# Слияние односвязных списков

# Решение

Реализованы два способа: с фиктивным начальным узлом и без него.

В обоих случаях сравниваются первые ещё не добавленные узлы двух списков. Узел с меньшим значением присоединяется к результату, после чего указатель в соответствующем списке сдвигается вперёд. Когда один список заканчивается, оставшаяся часть второго списка присоединяется целиком.

В решении с фиктивным элементом он упрощает добавление первого узла, но не входит в ответ. В решении без фиктивного элемента головой результата сразу становится меньший из первых узлов.

Новые узлы для элементов не создаются: результат собирается из узлов исходных списков.

# Сложность

Время: O(n + m), где n и m — длины исходных списков. Каждый узел рассматривается один раз.

Дополнительная память: O(1), потому что используются только несколько ссылок. Фиктивный узел также занимает O(1) памяти.

# Пример работы

Для списков `[1, 2, 4]` и `[1, 3, 4]`:

| Сравниваем | Выбираем | Результат |
| --- | --- | --- |
| 1 и 1 | 1 из первого списка | [1] |
| 2 и 1 | 1 из второго списка | [1, 1] |
| 2 и 3 | 2 | [1, 1, 2] |
| 4 и 3 | 3 | [1, 1, 2, 3] |
| 4 и 4 | 4 из первого списка | [1, 1, 2, 3, 4] |
| первый список пуст | остаток второго списка | [1, 1, 2, 3, 4, 4] |
