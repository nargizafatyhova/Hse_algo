# Стек и очередь

# Решение

Стек и очередь реализованы на основе односвязного списка.

У стека добавление и удаление происходит в начале списка. Поэтому элементы выходят в обратном порядке: последним пришёл — первым вышел (LIFO).

У очереди хранятся ссылки на начало и конец списка. Новый элемент добавляется в конец, а удаляется из начала. Поэтому элементы выходят в порядке добавления: первым пришёл — первым вышел (FIFO).

# Сложность

Для стека операции `push`, `pop` и `peek` работают за O(1).

Для очереди операции `enqueue`, `dequeue` и `peek` работают за O(1), потому что отдельно хранится ссылка на последний узел.

Память: O(n), где n — количество элементов в структуре.

# Пример работы

Добавим числа 1, 2 и 3.

Стек:

`пусто -> [1] -> [2, 1] -> [3, 2, 1]`

При удалении получим: 3, 2, 1.

Очередь:

`пусто -> [1] -> [1, 2] -> [1, 2, 3]`

При удалении получим: 1, 2, 3.
