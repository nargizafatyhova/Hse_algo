# Простые числа

# Решение

Программа использует решето Эратосфена. Сначала все числа считаются простыми. Затем программа отмечает составные числа как False, начиная с кратных 2. После этого подсчитывается количество оставшихся простых чисел меньше N.

# Сложность

Время: O(n log log n).

Память: O(n), потому что создаётся список длины n.

# Пример работы

Для N = 10:

Рассматриваем числа от 2 до 9
Убираем кратные 2: 4, 6, 8
Убираем кратные 3: 9
Остаются простые числа: 2, 3, 5, 7
Количество: 4
