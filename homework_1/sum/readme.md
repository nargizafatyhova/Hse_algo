# Максимальная чётная сумма

# Решение

Сначала программа находит сумму всех чисел.

Если сумма чётная, она является максимальным ответом. Если сумма нечётная, программа вычитает из неё наименьшее нечётное число. После этого сумма становится чётной и остаётся максимально возможной.

# Сложность

Время: O(n), n — количество чисел.

Память: O(1), потому что дополнительные списки не создаются.

# Пример работы

Для чисел 5 7 13 2 14:

Общая сумма: 41
Сумма нечётная
Нечётные числа: 5, 7, 13
Наименьшее нечётное число: 5
41 - 5 = 36
Ответ: 36
