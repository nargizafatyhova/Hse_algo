# Палиндром

# Решение

Программа проверяет, является ли положительное число палиндромом без использования строк.

На каждой итерации последняя цифра числа берётся с помощью `% 10` и добавляется в перевёрнутое число. Затем последняя цифра удаляется с помощью `// 10`. В конце исходное и перевёрнутое числа сравниваются.

# Сложность

Время: O(k), k — количество цифр числа.

Память: O(1), потому что используется несколько переменных.

# Пример работы

Для числа 121:

x = 121, rev = 0
x = 12, rev = 1
x = 1, rev = 12
x = 0, rev = 121
121 == 121, поэтому результат True
